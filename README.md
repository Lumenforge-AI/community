# Join Lumenforge AI

Low-threshold membership. You do not need prior contributions, a sponsor, or a long application.

## How to join

1. Open a new issue in this repository: [New issue](https://github.com/Lumenforge-AI/community/issues/new?template=join.yml)
2. Use the title **Join Lumenforge AI**. The template fills this in.
3. Add your GitHub username and a one-line introduction. Say what you want to build or learn.
4. An owner reviews the issue and sends a GitHub organization invite.
5. Accept the invite from your GitHub notifications.
6. Make the membership public: [People](https://github.com/orgs/Lumenforge-AI/people) → your name → Public.

## What we ask

- Be a real person with a GitHub account.
- Keep the intro short and specific.
- Be decent in issues and pull requests.

## What we do not ask

- No minimum stars, followers, or merged pull requests.
- No referral or sponsor.
- No payment.

## After you join

- Read pinned issues before opening a project idea.
- Small documentation and experiment pull requests are welcome.
- Owners can remove inactive spam accounts.

Questions go in an issue titled **Question**.
